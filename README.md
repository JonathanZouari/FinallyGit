# Tic-Tac-Toe

A command-line Tic-Tac-Toe game in Python. Play against another person, or against a computer that uses minimax and never loses.

## Requirements

- Python 3

## Run

```bash
python Tictactoe.py
```

## How to play

1. Choose a mode: `1` for two players, or `2` to play the computer.
2. Against the computer, choose `#` (you go first) or `!` (the computer goes first).
3. On your turn, enter a square number from `1` to `9`. Empty squares show their numbers on the board.
4. The first player to get three marks in a row, column, or diagonal wins. A full board with no winner is a draw.
5. After the game, type `y` to play again or `n` to quit.

```
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```
