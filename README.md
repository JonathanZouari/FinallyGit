# Tic-Tac-Toe

A terminal Tic-Tac-Toe game written in Python. Play against a friend or against an unbeatable computer opponent (minimax).

## Requirements

- Python 3 (no third-party packages)

## How to run

```bash
python Tictactoe.py
```

## Modes

1. **Two players** — take turns as X and O on the same keyboard  
2. **Vs computer** — choose X (goes first) or O; the computer plays optimally

Squares are numbered **1–9** left to right, top to bottom. Enter a number to place your mark. After each game you can play again or quit.
