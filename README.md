# Tic-Tac-Toe

A Tic-Tac-Toe game written in Python. Play against another person or against the computer in a window.

## Requirements

- Python 3

## Run

```bash
python Tictactoe.py
```

## How to play

At the start of each game, choose a mode:

1. **Two players** — you and another person take turns clicking squares. `?` always goes first.
2. **Vs computer** — play as `?` (goes first) or `&`. The computer uses minimax and plays a perfect game, so the best result against it is a draw.

Click an empty square on your turn. Taken squares show `?` or `&`. After a win or a draw, press New game to play again.
