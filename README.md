# Tic-Tac-Toe

A terminal Tic-Tac-Toe game in Python. Play with two players or against the computer (minimax).

## Run

```bash
python Tictactoe.py
```

Requires Python 3. No extra dependencies.

## Game modes

1. **Two players** — X and O take turns on the same computer.
2. **Vs computer** — choose X (goes first) or O. The computer plays optimally.

The board is numbered 1–9. After each game you can start another one.
