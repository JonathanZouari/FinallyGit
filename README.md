# Tic Tac Toe

A Python implementation of the classic Tic Tac Toe game.

## Overview

This project provides a simple command-line implementation of Tic Tac Toe, allowing two players to compete against each other on a 3x3 grid.

## Features

- Two-player gameplay
- Interactive command-line interface
- Board state visualization
- Win detection and draw detection
- Input validation

## Requirements

- Python 3.x

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd FinallyGit
   ```

2. No additional dependencies required - uses only Python standard library.

## Usage

Run the game:
```bash
python Tictactoe.py
```

Follow the on-screen prompts to:
- Enter your moves by specifying row and column positions
- Take turns between Player X and Player O
- Continue until someone wins or the board is full

## Game Rules

- The game is played on a 3x3 grid
- Players take turns marking spaces with their symbol (X or O)
- The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins
- If all 9 spaces are filled without a winner, the game is a draw
