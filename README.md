# Tic-Tac-Toe

משחק איקס-עיגול בטרמינל ב-Python. אפשר לשחק נגד שחקן שני או נגד המחשב (minimax).

## דרישות

- Python 3

אין תלויות חיצוניות.

## הרצה

```bash
python Tictactoe.py
```

## איך משחקים

1. בחרו מצב: `1` לשני שחקנים, `2` נגד המחשב.
2. במשחק נגד המחשב אפשר לבחור `X` (מתחיל) או `O`.
3. בכל תור מזינים מספר משבצת מ-1 עד 9:

```
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

4. בסוף המשחק אפשר להתחיל סיבוב חדש (`y`) או לצאת.
