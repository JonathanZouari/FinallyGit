# Tic-Tac-Toe

A command-line Tic-Tac-Toe game in Python. Play against another person or against the computer.

## Requirements

- Python 3

## How to run

```bash
python Tictactoe.py
```

## Game modes

1. **Two players** — take turns as X and O on the same keyboard.
2. **Vs computer** — play against an unbeatable opponent (minimax). Choose X (goes first) or O.

Squares are numbered 1–9, left to right, top to bottom:

```
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

After each game you can play again or quit.
